# Orçamento de erro para SLO

Linguagem: Python

## Pré-requisitos
Funções, dicionários, módulos e leitura de arquivos.

## 1. Problema
Calcular quantas falhas ainda cabem no orçamento inteiro e se ele foi excedido. Saída por linha: restante não negativo e flag 1 de excesso.

## 2. Decisão de arquitetura
O orçamento é derivado do número de requisições observadas. Uma taxa de erro sem volume esconde impacto. Funções puras, validação de tipos em runtime, listas e unittest. A CLI usa o módulo csv e mantém leitura de arquivos separada da regra.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | total | 1 | 10000 |
| 1 | failed | 0 | 10000 |
| 2 | slo_basis_points | 0 | 10000 |

## 5. Resultado esperado
```
[5,0,0,1]
```

## 6. Critérios de aceite
- Caso 1: entrada [[10000,5,9990],[1000,2,9990]] deve produzir [5,0,0,1].
- Caso 2: a entrada inválida deve falhar, sem resposta parcial.
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
