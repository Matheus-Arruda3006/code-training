# Escalonador de jobs em três workers

Linguagem: Python

## Pré-requisitos
Funções, dicionários, módulos e leitura de arquivos.

## 1. Problema
Atribuir cada job ao worker que ficará livre primeiro, respeitando a chegada. Saída: pares índice do worker, instante de término. Empate favorece menor índice.

## 2. Decisão de arquitetura
Calcule início como máximo entre chegada e disponibilidade. Esse modelo torna a espera na fila observável. Funções puras, validação de tipos em runtime, listas e unittest. A CLI usa o módulo csv e mantém leitura de arquivos separada da regra.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | arrival | 0 | 10000 |
| 1 | duration | 1 | 10000 |

```sh

```


## 5. Resultado esperado
```
[0,5,1,2,2,3,1,3]
```

## 6. Critérios de aceite
- Caso 1: entrada [[0,5],[0,2],[0,3],[1,1]] deve produzir [0,5,1,2,2,3,1,3].
- Caso 2: entrada [[10,2]] deve produzir [0,12].
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
