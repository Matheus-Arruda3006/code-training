# Seleção de backlog por orçamento

Linguagem: Python

## Pré-requisitos
Funções, dicionários, módulos e leitura de arquivos.

## 1. Problema
Escolher subconjunto de itens com custo total <=50 que maximize valor. Cada item pode ser usado uma vez. Saída: valor máximo.

## 2. Decisão de arquitetura
Atualizar a capacidade em ordem decrescente evita reutilizar o mesmo item durante a passagem: é mochila 0/1, não ilimitada. Funções puras, validação de tipos em runtime, listas e unittest. A CLI usa o módulo csv e mantém leitura de arquivos separada da regra.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | cost | 1 | 50 |
| 1 | value | 0 | 10000 |
