# Estimador de capacidade por crescimento

Linguagem: Python

## Pré-requisitos
Funções, dicionários, módulos e leitura de arquivos.

## 1. Problema
Estimar dias inteiros até alcançar a capacidade. Já saturado retorna 0; sem crescimento retorna -1. Saída: dias por recurso.

## 2. Decisão de arquitetura
Use divisão com teto: arredondar para baixo anuncia saturação antes do primeiro dia inteiro que realmente alcança o limite. Funções puras, validação de tipos em runtime, listas e unittest. A CLI usa o módulo csv e mantém leitura de arquivos separada da regra.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | current | 0 | 10000 |
| 1 | daily_growth | 0 | 100 |
| 2 | capacity | 1 | 10000 |

```

```

## 6. Critérios de aceite
- Caso 1: entrada [[90,3,100],[100,0,100],[10,0,100]] deve produzir [4,0,-1].
- Caso 2: entrada [[0,1,1]] deve produzir [1].
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
