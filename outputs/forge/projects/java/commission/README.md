# Comissões com estorno e teto

Linguagem: Java

## Pré-requisitos
Classes, interfaces, listas e exceções.

## 1. Problema
Calcular comissão sobre vendas líquidas, arredondada para baixo e limitada pelo teto por vendedor. Saída: comissão em centavos.

## 2. Decisão de arquitetura
Estornos reduzem a base; uma base negativa vira zero. Basis points expressam taxas em inteiros, evitando ambiguidade percentual. Tipos long, arrays, ArrayList e exceções. O núcleo não acessa arquivo nem estado global, facilitando testes e integração futura com serviços.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | sold | 0 | 10000 |
| 1 | returned | 0 | 10000 |
| 2 | basis_points | 0 | 10000 |
| 3 | cap | 0 | 10000 |

1. Defina o contrato: Calcular comissão sobre vendas líquidas, arredondada para baixo e limitada pelo teto por vendedor. Saída: comissão em centavos.

2. Crie os arquivos de domínio e leia a decisão: Estornos reduzem a base; uma base negativa vira zero. Basis points expressam taxas em inteiros, evitando ambiguidade percentual.

3. Implemente o adaptador da linguagem: Tipos long, arrays, ArrayList e exceções. O núcleo não acessa arquivo nem estado global, facilitando testes e integração futura com serviços.

4. Execute os testes antes de usar input.tsv. Os valores esperados são fixos e independentes do retorno calculado.

5. Faça uma extensão autoral: Adicione uma tabela de faixas e uma trilha de auditoria da política aplicada.

## 3. Crie os arquivos
- Domain.java
- Main.java
- Tests.java
- input.tsv

## 4. Execute na pasta do projeto
```sh
javac --release 17 Domain.java Main.java Tests.java
java Tests
java Main input.tsv
```


## 5. Resultado esperado
```
[800,0]
```

## 6. Critérios de aceite
- Caso 1: entrada [[10000,1000,1000,800],[100,200,500,100]] deve produzir [800,0].
- Caso 2: entrada [[999,0,1000,1000]] deve produzir [99].
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
