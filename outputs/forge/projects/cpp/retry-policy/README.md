# Planejador de retentativas com backoff

Linguagem: C++

## Pré-requisitos
Templates básicos, referências, containers e iteradores.

## 1. Problema
Produzir atraso exponencial limitado, com jitter determinístico entre metade e o valor máximo. Saída: atraso por tarefa; tentativa zero usa o atraso base.

## 2. Decisão de arquitetura
Jitter evita clientes sincronizados. A semente permite testar o planejamento sem depender de aleatoriedade global. RAII, std::vector, referências const e exceções. O arquivo é fechado pelo destrutor e a memória acompanha a vida dos containers.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | attempt | 0 | 12 |
| 1 | base | 1 | 100 |
| 2 | cap | 1 | 10000 |
| 3 | seed | 0 | 10000 |

1. Defina o contrato: Produzir atraso exponencial limitado, com jitter determinístico entre metade e o valor máximo. Saída: atraso por tarefa; tentativa zero usa o atraso base.

2. Crie os arquivos de domínio e leia a decisão: Jitter evita clientes sincronizados. A semente permite testar o planejamento sem depender de aleatoriedade global.

## 4. Execute na pasta do projeto
```sh
c++ -std=c++17 -Wall -Wextra tests.cpp -o tests
./tests
c++ -std=c++17 -Wall -Wextra main.cpp -o app
./app input.tsv
```


## 5. Resultado esperado
```
[5,35]
```

## 6. Critérios de aceite
- Caso 1: entrada [[0,10,100,0],[3,10,50,10]] deve produzir [5,35].
- Caso 2: entrada [[12,100,10,100]] deve produzir [9].
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
