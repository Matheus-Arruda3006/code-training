# Monitor de média móvel

Linguagem: C#

## Pré-requisitos
Classes, métodos, coleções e exceções em C#. Para este projeto adicional, instale SDK .NET 10.

## 1. Problema
Calcular média inteira dos últimos 3 pontos, usando janela parcial no início. Saída: média truncada após cada medição.

## 2. Decisão de arquitetura
Subtrair o item que sai da janela evita somar todos os pontos novamente. A janela mede eventos, não duração. Métodos estáticos puros, long, List<long> e exceções de contrato. Overflow é verificado pelo projeto; os adaptadores não contêm regras de negócio.

## Contrato de dados

TSV com cabeçalho e até 200 registros. Cada campo é um inteiro dentro dos limites inclusivos. Na API .NET, envie as linhas como arrays em data.

| Índice | Campo | Mínimo | Máximo |
|---|---|---|---|
| 0 | measurement | 0 | 10000 |

## Roteiro guiado

1. Defina o contrato: Calcular média inteira dos últimos 3 pontos, usando janela parcial no início. Saída: média truncada após cada medição.

2. Crie os arquivos de domínio e leia a decisão: Subtrair o item que sai da janela evita somar todos os pontos novamente. A janela mede eventos, não duração.

3. Implemente o adaptador da linguagem: Métodos estáticos puros, long, List<long> e exceções de contrato. Overflow é verificado pelo projeto; os adaptadores não contêm regras de negócio.

4. Execute os testes antes de usar input.tsv. Os valores esperados são fixos e independentes do retorno calculado.

5. Faça uma extensão autoral: Adicione média por intervalo de tempo e compare a influência de amostragem irregular.

## 5. Resultado esperado
```
[10,15,20,50]
```

## 6. Critérios de aceite
- Caso 1: entrada [[10],[20],[30],[100]] deve produzir [10,15,20,50].
- Caso 2: entrada [[1],[2]] deve produzir [1,1].
- Caso 3: entrada [] deve produzir [].
- Rejeitar colunas incorretas, valores fora dos limites e mais de 200 registros.
